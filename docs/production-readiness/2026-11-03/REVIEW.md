## Architecture and product boundary

The documented entry is `python -m egoshield.daemon.main`; the extension loads a content script and service worker. The content script gathers visible page text and sends it to the background worker, which hashes the URL and posts content and domain to a loopback daemon; the daemon wires analysis, rules, settings and SQLite services. Ollama is optional. Sources: [README:35-46](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/README.md#L35-L46), [content.js:52-101,105-124](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/extension/js/content.js#L52-L124), [background.js:293-305](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/extension/js/background.js#L293-L305), [main.py:125-145](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/egoshield/daemon/main.py#L125-L145). Dashboard and email-reader internals were not inspected; email or cross-browser support is not established.

## Findings ledger

**EGO-01 — High, confirmed static; high confidence. Local API trust is not authentication.** [main.py:87-107,185-214](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/egoshield/daemon/main.py#L87-L214) accepts requests with no Origin, accepts any extension origin when no ID is configured, and uses `origin.startswith` for dashboard origins, including ports beginning with `8766`. [routes.py:254-255,331-344,461-477](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/egoshield/daemon/api/routes.py#L254-L477) exposes rule creation, setting updates and history without a route-level credential in those handlers. A local process can access these routes; browser exploitability depends on browser origin/CORS behavior and was not tested. Localhost is not a per-user authorization boundary. Add authenticated local IPC or a carefully provisioned capability, exact origin matching and authorization on sensitive routes; define the same-user threat model first.

**EGO-02 — High, confirmed static; high confidence. Trust removal and failed writes diverge.** [background.js:164-182](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/extension/js/background.js#L164-L182) removes an already trusted domain only from the local array with `state.trustedDomains.splice(index, 1)`; adding occurs before the daemon POST, whose failure is caught while local state is still saved. [routes.py:178-193](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/egoshield/daemon/api/routes.py#L178-L193) returns a zero-score trusted result for a daemon-trusted domain. Removal may leave the daemon bypass active and a later refresh can restore it; a failed add may still locally bypass analysis. Make the daemon authoritative, delete the matching rule remotely, and update local state only after confirmation.

**EGO-03 — Medium, confirmed static; high confidence. Dismissing annotations changes page text.** [content.js:291-304,374-380](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/extension/js/content.js#L291-L380) appends a tooltip inside each annotation and later replaces the wrapper with `wrapper.textContent`; that includes tooltip text as well as the original match. Clearing the overlay can inject tooltip text into the host page. Preserve and restore only the original matched text, and exercise repeated annotate/dismiss cycles in a real browser.

**EGO-04 — Medium, confirmed static; high confidence. Release entry and extension assets need repair.** [pyproject.toml:56-64](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/pyproject.toml#L56-L64) declares `daemon.main:main`, while the complete pinned tree places the code under `egoshield/daemon/` and has no top-level `daemon` package. The [extension manifest:27-40](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/extension/manifest.json#L27-L40) references `icons/icon16.png` and other sizes; the non-truncated 72-path tree contains no `extension/icons/` files. The installed command and unpacked extension are therefore at risk; exact browser/install failure is unverified. Correct packaging and supply or deliberately remove asset references, then test built artifacts in clean environments.

**EGO-05 — Medium, confirmed static plus historical CI; high confidence. Green CI is compile-only.** [ci.yml:9-19](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/.github/workflows/ci.yml#L9-L19) installs requirements and runs `python -m compileall -q .`, not pytest. The sampled [plugin tests:104-122](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/tests/unit/test_plugins.py#L104-L122) claim security checks but assert only an exception exists or a class name. [Run 36902580078](https://github.com/knarayanareddy/EGOSHIELD/actions/runs/36902580078) historically succeeded at this exact SHA; it is not evidence of behavior or test success. Add collected behavioral tests and negative controls to CI.

**EGO-06 — Medium, confirmed static; high confidence. Rate limits are caller-selectable and size uses characters.** [routes.py:94-98,162-175,195-200](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/egoshield/daemon/api/routes.py#L94-L200) uses `X-EgoShield-Client` directly as limiter identity and compares `len(body.content)` to a limit described as bytes. A caller can vary the header and multibyte text can exceed the stated byte limit. Bind limits to authenticated identity and enforce a request/body byte budget before expensive processing.

## Five-discipline assessment

- **Correctness/code review:** EGO-02, EGO-03 and EGO-04 affect documented use; [README:42-47](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/README.md#L42-L47) promises an unpacked extension. Detector accuracy and email ingestion remain unverified.
- **Automation/testing:** EGO-05 separates historical compilation from test execution. [Integration tests:21-55](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/tests/integration/__init__.py#L21-L55) include real SQLite assertions, but collection and outcomes are unknown.
- **DevOps/operations:** [main.py:125-133,157-159](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/egoshield/daemon/main.py#L125-L159) runs migrations and retention at startup and closes on shutdown. Backup consistency, restore, release signing and operating-system service lifecycle are not verified.
- **OWASP/security:** EGO-01/EGO-06 concern authorization and resource limits. The sampled [delete route:300-304](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/egoshield/daemon/api/routes.py#L300-L304) parameterizes its SQL; other injection and plugin paths are unassessed. [requirements.txt:1-5](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/requirements.txt#L1-L5) uses lower bounds; lockfile use and dependency integrity are unverified. [security.md:75-85](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/docs/security.md#L75-L85) promises no content or credentials stored, but storage, logs, keyring and optional model transport were not traced end-to-end. No claim that secrets are safe or exposed is supported.
- **UI/UX/accessibility:** EGO-03 corrupts the underlying document on dismissal. [content.js:263-270,306-310](https://github.com/knarayanareddy/EGOSHIELD/blob/9123a622f9460bf0621b18f17266f5e06e6a833c/extension/js/content.js#L263-L310) provides focusable annotations and focus handlers; keyboard semantics, screen-reader output and contrast require browser testing. Failure visibility and trusted-domain recovery need user testing.

## Production blockers and owner decisions

Block release on authenticated local access, correct trust revocation, verified packaging and real behavioral/browser gates. Owner must define supported browsers/OS, whether same-user processes are adversarial, extension identity/provisioning, optional Ollama locality, accuracy/false-positive acceptance and consent boundaries for sensitive pages. Decide distribution signing, release accounts, SQLite backup/restore and retention policy. No credentials, account access or deployed environment were checked.
